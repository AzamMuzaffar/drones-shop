# Dronely

A modern drone ecommerce landing page built with React + Vite. This project is designed to look polished and professional for a portfolio or interview presentation.

## Features
- Premium product showcase for drones
- Category filtering
- Add-to-cart functionality
- Stripe-style mock checkout experience
- Responsive layout for mobile and desktop
- GitHub Pages ready

## Local development
```bash
npm install
npm run dev
```

## Build for production
```bash
npm run build
```

## Deploy to GitHub Pages
1. Run `npm run build`
2. Push the repo to GitHub
3. In the GitHub repository, open Settings → Pages
4. Select the `main` branch and `/ (root)` folder, or use a static deploy workflow if preferred
5. Save and wait for deployment

## Notes
This is a front-end storefront demo and does not process real Stripe payments. The checkout section is designed to look like a real Stripe checkout flow for presentation purposes.
